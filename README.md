# 🌦️ Futuristic Weather App

A modern and futuristic Weather Application built using **HTML, CSS, and JavaScript**, powered by the **AccuWeather API**. Users can enter a city name to get current weather information through an attractive, futuristic user interface.

## ✨ Features

* 🌍 **City-Based Weather Search** – Search for weather information by entering a city name.
* 🌡️ **Live Weather Information** – Displays the current temperature and weather conditions for the selected city.
* 🌤️ **Dynamic Weather Icons** – Displays weather icons according to the current weather conditions.
* 💨 **Wind Speed** – Shows the current wind speed with a dedicated icon.
* 💧 **Humidity Information** – Displays the current humidity percentage with an icon.
* ❌ **Error Handling** – Shows an error message when the entered city name is invalid or weather information cannot be retrieved.
* 🎨 **Futuristic UI Design** – Features a modern interface with attractive colors, stylish elements, and a technology-inspired appearance.
* 📱 **Responsive Layout** – Designed to provide a convenient experience across different screen sizes.
* ⚡ **Real-Time API Integration** – Fetches weather information from the AccuWeather API.

## 🛠️ Technologies Used

* **HTML5** – Structures the weather application.
* **CSS3** – Creates the futuristic design, layout, and visual effects.
* **JavaScript** – Handles user input, API requests, weather data, and error messages.
* **AccuWeather API** – Provides location-based weather information.

## 🌦️ Weather Information

The application displays the following information for the searched city:

| Feature           | Description                              |
| ----------------- | ---------------------------------------- |
| City Name         | Name of the searched city                |
| Temperature       | Current temperature                      |
| Weather Condition | Description of the current weather       |
| Weather Icon      | Icon representing the current weather    |
| Wind Speed        | Current wind speed with an icon          |
| Humidity          | Current humidity percentage with an icon |

## 🔑 API Integration

This project uses the AccuWeather API to retrieve weather information based on the city entered by the user.

The application uses the following API functionality:

* **Location Search API** – Finds the location key for the entered city.
* **Current Conditions API** – Retrieves temperature, weather descriptions, weather icons, wind speed, and humidity.

Official documentation: [AccuWeather Developer Portal](https://developer.accuweather.com/)
